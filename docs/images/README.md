# Screenshots & Demo Media Directory

Place your extension screenshots, demonstration GIFs, and video assets in this folder.

Recommended files:
- `demo.gif` or `demo.mp4` — High-level walkthrough showing form detection, preview review, and filling.
- `screenshot-preview.png` — The Form Preview Modal showing matched questions, confidence badges, and sensitive field opt-ins.
- `screenshot-popup.png` — Extension popup interface showing detected form summary and page type badge.
- `screenshot-options.png` — Profile and custom fields settings dashboard.
